# Память Материи — игровой репозиторий

Top-down физическая action-RPG для Android (Unity 6.3 LTS / 6000.3.x).
Игрок — слизень: импульсное движение, вода, биогравитация, поглощение, гены, душа.

**Версия сборки:** v0.3.1 — объединение v0.3.0-demo-complete и v0.3.0-graphics (2026-10-26).
**Статусы проверки:** Domain-логика — TESTED (harness PASS);
Unity-компиляция и запуск — см. историю коммитов (сборка APK и установка на устройство).

## Что нового в v0.3.0-graphics (визуал и мобильный UI)

- **Графика мира (без ассетов, всё процедурно):** фон-свечение арены, пол/стены со
  скруглениями и световыми кромками (стены теперь видимы), слайм — мембрана + ядро +
  блик + «дыхание», жуки — панцирь, голова, глаза, гранулы — свечение, брызги при рывке,
  прицел — градиентная линия с наконечником. Спрайт-круг теперь ровно 1:1 с коллайдером
  (раньше визуал был 2×).
- **Мобильный HUD:** якоря по краям с SafeArea, тач-зоны ≥ 100 px (пауза 116×116,
  «ГЕНЫ» 260×116), скруглённые панели, цветные маркеры статусов (целостность краснеет
  при < 35%), полоса удержания у нижней кромки, подсказка тянется на всю ширину.
- **Важно:** HUD запечён в `Boot.unity`. После pull повторно запустите
  **PM/Setup/01 Create Boot Scene** — сцена пересоздастся с новым HUD (идемпотентно).

## Новое в v0.3.0

- **Формы доступны игроку (T12, был разрыв цикла):** экран «ГЕНЫ» → раздел «Формы» —
  хитиновая модификация, форма жука, возврат в слизь (возврат 80% вложений);
  форма меняет цвет и масштаб тела и органы.
- **Социальная развилка (T16):** кнопка «ПОМОЧЬ союзнику» (вода → союзнику, Trust+20,
  союзник приходит на помощь при ослаблении); удары по ИИ запоминаются (бегство/месть);
  носители душ помечены «(ИИ)» — релиз-критерий.
- **Химическое чутьё (T14):** узел n_chem_sense включает зелёную стрелку к ближайшей пище
  (радиус 6 м, только наблюдаемые факты).
- **Обучение (T18):** цепочка контекстных подсказок по событиям мира (первая пища,
  ослабление жука, ген, узел, помощь, кража воды) — раньше статичная подсказка гасла в первый кадр.
- **Звук (T19-минимум) + настройка:** процедурные сигналы (рывок, еда, захват, удар,
  узел, смерть, помощь); громкость «Звук −/+» в паузе, хранится в PlayerPrefs.
- **Финал демо:** после первой реинкарнации — экран «Круг замкнулся» с приглашением
  оставить отзыв/поддержать проект (критерий «очевидное завершение»).
- **Экран смерти:** реальная статистика жизни (гранулы, добыча, узлы, помощь).
- **Критический фикс запечённой сцены:** code-added onClick-слушатели не переживают
  сохранение сцены, а Awake/Start неактивных панелей не запускаются — все кнопки
  (пауза, гены, сохранения, реинкарнация) теперь навешиваются идемпотентным
  `Wire()`/`RewireRuntime()` в runtime; новые HUD-элементы достраиваются без пересохранения сцены.
- **Гигиена:** из git удалён мусор сборки `.utmp/` (109 файлов), добавлен в .gitignore;
  bundleVersion 0.3.0; меню PM/Setup/04 Build APK.

## Быстрый старт (проверка владельцем)

1. **Unity Hub** → установить **Unity 6000.3.x (LTS)** с модулем **Android Build Support**
   (OpenJDK + Android SDK Tools включить).
2. Открыть проект (версия в `ProjectSettings/ProjectVersion.txt`: 6000.3.10f1 —
   при несовпадении патча Hub предложит открыть установленной: согласиться).
3. Дождаться импорта. Меню: **PM/Setup/01 Create Boot Scene** → сцена создастся кодом
   и добавится в Build Settings.
4. **PM/Setup/02 Apply Android Settings** → IL2CPP, ARM64, minSdk 24, Linear, landscape,
   пакет `com.pamyatmaterii.game`, версия 0.3.0.
5. **PM/Setup/03 Verify Project Wiring** → убедиться, что bootstrap/camera/HUD на месте.
6. Play — вертикальный цикл: оттянуть палец/мышь **против** движения → отпустить → рывок;
   гранулы притягиваются и усваиваются; жука ослабить ударами → подойти → удержание →
   пищеварение → «ГЕНЫ» → узлы (хитин → чутьё → форма) → раздел «Формы» → «Форма жука»;
   рядом с союзником — кнопка «ПОМОЧЬ союзнику» (вода → Trust); ударить ИИ — он запомнит;
   целостность 0 → экран смерти со статистикой → «РЕИНКАРНИРОВАТЬСЯ» → финальный экран демо.
7. Пауза («II») → сохранение/загрузка двух слотов + громкость «Звук − / +».
8. **PM/Dev/Game View 16:9 / 20:9** — проверить взятие камеры и safe area
   (если автопереключение не сработало — вручную, см. лог в Console).
9. **PM/Setup/04 Build APK** → `build/PamyatMaterii.apk` (нужен модуль Android Build Support).
10. Тесты Domain вне Unity: `cd tools/dotnet-tests && dotnet run` → `PASSED 450/450`.
11. Тесты Unity: Window → General → Test Runner → EditMode → Run All (5 дымовых).

  Unity-слой v0.2.0 = TESTED UNITY/DEVICE владельцем; новые системы v0.3.0 = CODE COMPLETE
  (после шагов 3–11 — TESTED UNITY).

## Ограничения демо-сборки (честно)

- Арт — процедурные круги палитры VISUAL_UI; анимации — scale/цвет; звук — процедурные сигналы.
- Органы после реинкарнации восстанавливаются из знаний мгновенно (в полной игре — время/компоненты).
- Имена ИИ-душ — плейсхолдеры (`ai_ally`, `ai_rival`), до утверждения владельцем;
  ссылки отзыва/поддержки на финальном экране — плейсхолдеры до страницы релиза.
- Яд/холод/тепло, магия, маскировка — вне демо (DEMO_SCOPE «не включаем»).
- Локализация — RU (DEMO_SCOPE п.10), публикация/страница релиза — T20.
