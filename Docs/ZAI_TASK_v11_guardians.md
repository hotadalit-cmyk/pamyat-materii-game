Не удалять и не ослаблять существующие тесты. Можно менять существующие файлы, но минимально и только нужное.
Коммить по ходу. Отчёт ≤ 15 строк.

## Наши реальные числа (твои таблицы — в другом масштабе!)
Старт массы героя 4 (`RunState.StartMass`). Цель глубины = `World.GoalMass` (25% массы всех существ карты, мин. 6).
Сейчас страж есть только на Г5: `BossState` (масса 30, фазы Charge/Brood/Frenzy/Exposed, поглощается при <30% массы).
HP стража = его масса. Формула HP стража глубины: `max(8, GoalMass × HpMult)`, HpMult: Г1 1.3, Г2 1.35, Г3 1.4, Г4 1.45, Г5 1.5.

## Что сделать
1. **Domain: данные и общий автомат стражей**
   - `GuardianDef` (Id, Name, Depth, SpeciesId, HpMult, ArenaRadius, PhaseThresholds {0.66, 0.33}, телеграфы, параметры атак)
     и `GuardianCatalog.ForDepth(int)` — 5 записей (Спороносица, Горнило, Хор Бездны, Гранильщик, Пульсар).
     На этом этапе полноценная механика нужна ТОЛЬКО Спороносице и Пульсару; Г2–Г4 временно используют
     поведение Пульсара со своими именами/цветом/HP (это пометить TODO этапа 2).
   - `GuardianState` (заменяет BossState по смыслу): Phase (0..N), Hp, Think(GuardianInput) → GuardianOutput.
     Output расширить: Impulse/Direction/Strength01 (как сейчас), SpawnMinions + MinionSpecies, Shockwave,
     **Zones** (список зон: позиция, радиус, урон массы/с, замедление, время жизни), **Telegraph** (позиция/радиус/секунды
     до удара — чтобы Unity нарисовал предупреждение), **WeakPointOpen** (bool, окно уязвимости).
   - Пульсар = нынешнее поведение BossState 1:1 (существующие RunBossTests должны остаться зелёными; BossState можно
     оставить фасадом над GuardianState или сохранить как есть — на твой выбор, но API `Run.Boss`, `BossPhase`,
     `ApplyHit`, `IsExposed`, `OnBossAbsorbed` не ломать, Unity их использует).
   - **Спороносица (Г1)**: неподвижна. Ф1: 4 зоны спор (r 2.5, −0.4 массы/с, замедление 30%) переставляются каждые 8 с;
     каждые 12 с два плесеника (SpeciesId "spore_mite" или существующий "mite", масса 1.5). Шляпка закрыта — урон
     только по корням (ApplyHit как сейчас, но ×0.5). Ф2 (66%): корни бьют по площади (телеграф 0.8 с, урон 12% массы игрока);
     каждые 8 с шляпка открывается на 2 с — WeakPointOpen, урон ×1.5. Ф3 (33%): зоны дрейфуют к игроку, плесеники вдвое чаще.
     Обнажена (<30% HP) → можно поглотить касанием, как сейчас.
2. **Domain: страж у выхода каждой глубины (открытый мир, `RunState.OpenWorld`)**
   - Пока цель глубины не набрана — страж спит (его нет на карте или он Dormant у шахты).
   - Цель набрана → `GuardianAwake` = true, страж появляется у шахты (`World.ExitPos`), арена радиуса ArenaRadius.
   - `ExitOpen` в открытом мире = цель набрана И страж поглощён (`OnBossAbsorbed`).
   - Окно отступления: пока Phase == 1, выход из арены (дальше ArenaRadius×1.5 от стража) — бой сбрасывается, страж
     восстанавливает HP; штраф — минус 25% текущей массы героя. После Ф1 сбежать нельзя.
   - Скрытая защита: после 2 поражений (смертей или отступлений) от стража ЭТОЙ глубины в этом забеге HP ×0.85.
   - Награда: эссенция по глубине (Г1 8, Г2 14, Г3 22, Г4 32, Г5 = текущие 40) + жетон эволюции.
   - Г5 сохраняет текущее поведение (страж с начала глубины) — ок, если станет «у шахты» как остальные.
3. **Тесты** `tools/dotnet-tests/Tests/RunGuardianTests.cs`: каталог 5 стражей; HP по формуле; пороги фаз;
   зоны Спороносицы переставляются по таймеру и детерминированы по сиду; WeakPointOpen окно 2 с из 8;
   ExitOpen только после поглощения; отступление в Ф1 сбрасывает бой, в Ф2 — нет; защита ×0.85 после 2 поражений;
   старые RunBossTests зелёные.
4. **Unity-слой (минимально, я доделаю):** в `RunGame.cs` — спавн стража у шахты при `GuardianAwake`, отрисовка
   Zones (полупрозрачные круги), Telegraph (красное кольцо, заполняющееся за N секунд), подсветка WeakPointOpen
   (зелёное кольцо стража), урон/замедление зон по герою; баннер «<Имя стража> пробуждается…». Используй уже
   существующие хелперы (SpriteUtil.AddSprite, GameFeel, ProceduralSfx, _ui.Banner). Имя стража — в RunUi вместо «Страж глубины».
