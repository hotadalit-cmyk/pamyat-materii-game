# AUDIT v0.14 — логика RunState / RunGame / клоны / эволюция / алхимия / наследие / автопилот

Дата: 2026-10-27 · Ветка: `zai/v14` · Прогон: PASSED 114720/114720 (52 набора) до аудита; исправления — с прогоном после.

## Найдено и исправлено

### 1. RunGame.cs:714 (BuildPuppetInput) — автопилот не дрейфует по инерции
- **Симптом**: `SelfVel = new Vec2(0, 0)` всегда — Unity никогда не передаёт скорость в PuppetBrain.
  Ветка «совсем пусто — дрейф по инерции» (PuppetBrain.Think, шаг 5) — мёртвый код: герой в режиме
  «Авто» без еды/целей резко останавливается вместо плавного скольжения; у клона под нитью то же,
  маскируется fallback-блужданием (Wander).
- **Исправление**: в `BuildPuppetInput` добавлен параметр `selfVel`; герой передаёт
  `_player.Rb.linearVelocity`, клон — `rb.linearVelocity`. Domain-логика уже покрыта тестами
  (PuppetTests: «совсем пусто — стоит по инерции» на SelfVel ≠ 0).

### 2. RunGame.cs:697 (BuildPuppetInput) — автопилот не видит тело стража
- **Симптом**: существа с `IsBoss` исключались из снимка мира; зоны/телеграфы стража автопилот
  обходил, а само ТЕЛО стража — нет. Автопилотный герой (и клон под нитью) спокойно замирает
  вплотную к стражу и ловит контактные удары (11–23% массы за удар по v0.14). Нарушение ТЗ v0.13:
  «бежать от ранящих ближе 4» — страж ранит больше всех.
- **Исправление**: при пробуждённом живом страже (открытый мир) в снимок добавляется
  `PuppetSense { Pos = тело, Mass = Guardian.Hp, Threatens = true }` — автопилот держит дистанцию
  и уходит из зоны контакта, бой по-прежнему остаётся за игроком (касание управления — ручной режим).
