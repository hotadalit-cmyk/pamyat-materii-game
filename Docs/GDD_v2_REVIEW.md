# GDD v2.0 от Z.ai — разбор и решения к утверждению

Источник: чат Z.ai, 2026-10-27. Полный текст документа — `Docs/GDD_v2_ZAI.txt`
(34 стр.: стражи, ИИ, поверхность, другие игроки, экономика, план на 24 недели).
Статус: **черновик, ждёт решений владельца**. В код ничего не внесено.

## Что берём почти без изменений

| Идея | Почему хорошо |
|---|---|
| Страж у каждого выхода, один фреймворк арен и фаз, 5 наборов данных | Пульсар (наш BossState) становится частным случаем; Хозяева поверхности — тот же код |
| Масса — билет на арену, страж — экзамен; вниз только через победу | Не ломает экономику целевой массы |
| Окно отступления до конца 1-й фазы и скрытое снижение HP стража на 15% после 2 поражений | Защита от фрустрации без «лёгкого режима» |
| Ум противников = слоты поведений на одном ядре, по глубинам 1→5 слотов | Растит сложность умом: бегство → стая → кайт/уклонение → засада/охота на клонов → приманка, разведчики, перегруппировка |
| Правило честности: кольца никогда не лгут, телеграфы 0,3–0,9 с | Сохраняет доверие к кольцам |
| Другие игроки сначала **без сервера**: «слепки душ» (эхо) — 40 вшитых + обмен файлом | Укладывается в правило «без сети»; немезиды и эхо — одна сущность |
| Заделы под онлайн: сид мира, действия-интенты, GUID, сейв = сид + дельты | Дешёво сейчас, дорого потом |

## Что нужно поправить под реальную игру

1. **Числа не совпадают с нашими.** Z.ai считает старт массой 10 и цели 35/60/95/140/200.
   У нас старт 4, страж Г5 — 30, цель глубины = 25% массы карты. Таблицы надо пересчитать
   в наших единицах (HP стража ≈ 1,3–1,5 цели глубины — пропорцию сохранить).
2. **Забег 45–70 минут.** Требует сохранения посреди жизни (автосейв, продолжение после
   закрытия приложения) — у нас его нет. Это обязательная работа до боссов на каждом уровне.
3. **Тренировка за «стабильную эссенцию».** Сейчас тренировка — за ресурсы внутри жизни
   (так решили раньше). Z.ai переносит её в мету. Нужно решение владельца.
4. **Две эссенции (сгорающая и стабильная) + сгусток памяти на 3 жизни.** Сильная идея,
   но меняет мету; вводить после стражей.
5. **Поверхность 1,6 × 1,6 км с чанками, логово из 12 построек, колония клонов с офлайн-добычей.**
   Объём большой; для первой версии хватит: Устье + 2 области + 1 Хозяин, логово из 3 построек.
   Порядок вырезания из гл. 10.2 принять.
6. **Онлайн (Б1–Б3).** По AGENTS.md сеть — только после отдельного утверждения. До конца
   плана — только вариант А.

## Предлагаемый первый этап (2 недели)

- Domain: `GuardianDef` (данные стража: HP, фазы, пороги, телеграфы, арена) и общий
  `GuardianState`; BossState переносится на него без изменения поведения (тесты Пульсара зелёные).
- Арена у шахты: пробуждение в 3 м от открытой шахты при целевой массе, кольцо арены,
  окно отступления, скрытое снижение HP.
- «Спороносица» (Г1): неподвижная, зоны спор, корни-хваты, слабая точка под шляпкой.
- Тесты .NET на фазы, пороги и защиту; проверка на телефоне.
