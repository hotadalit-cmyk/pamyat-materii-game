в режиме полной сборки («соберём весь проект, а потом буду проверять»). Ниже — выявленные

## Намеренно за пределами этой сборки (честные ограничения)

- Компиляция Unity-слоя и билд APK **не выполнялись** (Unity в среде сборки недоступен) —
  статус NOT RUN, проверка возлагается на владельца по чек-листу README игрового репозитория.
- Арт, аудио, локализация, трейлер, страницы площадок — этапы T19–T20, не входят.
- Магические ауры, яд/холод/тепло, маскировка — отложены (P-08, DEMO_SCOPE «не включаем»).
- Имена и биографии ИИ-душ — не утверждены владельцем; используются плейсхолдеры `ai_ally`/`ai_rival`.
- Плейтест «интересности» (ворота D-21) — только после запуска сцены владельцем.

## Как проверять (кратко)

1. Открыть проект в Unity Hub (Unity 6000.3.x, Android Build Support).
2. Меню `PM/Setup/01 Create Boot Scene`, затем `PM/Setup/02 Apply Android Settings`, затем `PM/Setup/03 Build Demo Scene`.
3. Play: рывок оттягиванием, след, еда, биогравитация, жук: ослабить→захватить→переварить→узел генов→форма.
4. `Tools/Tests` вне Unity: `cd tools/dotnet-tests && dotnet run` — все тесты Domain зелёные.
5. Git-проверки: см. README игрового репозитория.
