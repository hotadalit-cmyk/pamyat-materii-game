# «Память Материи» — концепция v4 «Одна жизнь — один забег»

Дата: 2026-10-26. Заменяет игровую структуру GDD 3.0, сохраняя его мир, тему и механики-ядра.

## 1. Диагноз GDD 3.0

GDD 3.0 сильный по идеям, но в нём **пять равноправных систем** (физика, биология, душа,
социум, живой мир), и ни одна не отвечает на вопрос «что игрок делает в первые 30 секунд и
зачем возвращается завтра». В текущем прототипе это видно: арена, гранулы, жуки, меню генов —
и нет цели, нет нарастания, нет конца захода. Для мобильной игры одного разработчика с ИИ это
смертельно: каждая система требует контента, а удовольствие не складывается.

## 2. Главная идея v4

> **Смерть — не конец игры** — это готовая формула жанра *roguelite*.

- **Жизнь слизня = один забег** (5–10 минут, идеально для телефона).
- **Тело = билд забега**: масса и мутации, собранные из поглощённых существ. Теряется при смерти.
- **Душа = мета-прогресс**: переживает смерть, растёт от прожитого, открывает новые стартовые
  тела. Реинкарнация — это экран между забегами, а не отдельная механика.
- **Другие души = враги-немезиды**: ИИ-слизни тоже растут, умирают, перерождаются и **помнят
  тебя** между забегами.

Каждая система GDD получает ясную роль внутри одного цикла вместо параллельного существования.

## 3. Цикл за 30 секунд (ядро)

1. **Оттянул — отпустил — рывок** (бильярдное управление сохраняется: оно уже работает).
2. **Правило размера, понятное без обучения:** существо **меньше тебя** поглощается при
   касании; **больше тебя** — отталкивает и ранит. Крупных добычу сначала ослабляют
   рикошетами (удар = масса × скорость), потом поглощают.
3. **Масса — это всё сразу:** здоровье, сила удара, размер, радиус притяжения.
   Рывок стоит немного массы (капля влаги остаётся следом). Удар врага отрывает массу —
   она разлетается каплями, которые можно подобрать обратно. **Масса ниже порога — смерть.**
4. Рост меняет ощущение: большой слизень медленнее, но сносит всё; маленький — юркий.

Это и есть «масса — это жизнь» из GDD, но сведённая к одному числу на экране.

## 4. Цикл за 5 минут (забег)

- **Пещера из комнат.** Каждая комната — небольшая арена на один экран. Выход (светящаяся
  трещина) открывается, когда поглощено достаточно (цель комнаты).
- **Глубина 1 → 5**: грибной коридор → тёплый тоннель → кристальный зал → … → страж глубины.
  Глубже — крупнее и опаснее существа, больше эссенции.
- **Мутации:** каждый раз, когда масса переходит порог роста, выбор **1 из 3 мутаций**
  из генов поглощённых существ (шипы, липкость, яд в следе, панцирь, второй рывок, магнит,
  глаза и т.д.). Это и есть генетическая сеть GDD, только в виде быстрых решений внутри забега.
- **Тьма и восприятие:** пещера тёмная, слизень светится сам. Радиус видимости — мутация
  «глаза»; химическое чутьё — стрелка к еде. Темнота даёт атмосферу биолюминесценции
  без дорогой графики: на тёмном фоне светящиеся круги выглядят красиво.

## 5. Цикл между забегами (душа)

После смерти — экран **«Отпечаток жизни»**: глубина, поглощённые, лучший удар, немезида.

- Забег приносит **эссенцию** (за глубину, за поглощённых, за новые виды).
- Эссенция вкладывается в **три качества души** (из GDD): энергия (заряды рывка),
  выносливость (меньше потеря массы при рывке), магия (особая способность, позже).
- **Память генов:** вид, поглощённый впервые, навсегда добавляет свою мутацию в пул выбора.
- **Стартовые тела:** открываются за достижения (поглотил стража — можешь родиться жуком).
- Сила растёт **от мастерства, а не от фарма** (правило D-19 сохраняется: смерть сама
  ничего не даёт, награда — за прожитое, с убывающей отдачей).

## 6. Другие души (вместо отдельной социальной системы)

- В забеге встречаются 1–2 **ИИ-души** — слизни с именами (Искра, Осколок, Эхо…). Они тоже
  едят, растут и охотятся, в том числе на тебя.
- Если душа тебя убила — она **становится немезидой**: в следующих забегах появляется
  сильнее, с твоей мутацией и подписью «помнит тебя». Поглотить немезиду — большая награда.
- Если ты душу пощадил или накормил (отдал массу) — она может прийти на помощь позже.
- Это реализует «души помнят, перерождаются, меняют отношение» из GDD одной системой.

## 7. Что сохраняется из текущего кода

| Есть сейчас | Роль в v4 |
|---|---|
| Бильярдное управление, импульсы, отскоки | Без изменений — ядро |
| Масса тела (структура/вода/запас) | Сводится к одной видимой массе; вода = расход на рывок |
| Биогравитация | Пассивное притяжение мелочи, радиус от массы |
| Удары (ImpactDamage) | Ослабление крупной добычи и врагов |
| Влажный след | Визуал + расход массы; мутация «яд в следе» |
| Захват/пищеварение | Упрощается: мелкое — мгновенно, крупное — короткое переваривание |
| Гены/узлы | Превращаются в мутации 1-из-3 |
| Душа/реинкарнация | Мета-прогресс между забегами |
| ИИ-профили, память | Немезиды |
| Процедурная графика, мобильный HUD | Без изменений + тьма и свет |

Код не выбрасывается: меняется структура игры вокруг него.

## 8. Объём v0.4 (вертикальный срез)

1. Правило размера + масса как здоровье + капли массы при ударе.
2. Комнаты: генерация, цель комнаты, выход, глубина 1–5, рост сложности.
3. Мутации 1-из-3 (8–10 штук) при порогах роста.
4. Смерть → «Отпечаток жизни» → эссенция → 3 качества души → новый забег.
5. Тьма + свет слизня + видимость.
6. Одна ИИ-душа-немезида с памятью между забегами.

Вне объёма v0.4: стартовые тела, страж глубины, магия души, онлайн.
