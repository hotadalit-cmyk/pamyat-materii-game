# Приёмка и контроль качества

## Статусы
NOT STARTED / IN PROGRESS / CODE COMPLETE / TESTED LOCAL / TESTED UNITY / TESTED DEVICE / RELEASED. Не смешивать «код написан» и «игра протестирована».

## Минимальные тесты
1. **Вектор:** быстрые и медленные жесты, отмена pointer, касания по UI, ошибка направления отсутствует.
2. **Масса:** сохранение материального баланса, нулевые ресурсы, масса при переваривании/обратном подборе следа.
3. **Коллизии:** урон не начисляется многократно из-за дрожания или нескольких коллайдеров.
4. **Радиусы:** за пределом зоны эффект не применяется; стены блокируют по правилам; FPS не влияет на скорость обработки.
5. **Захват:** удержание живой добычи > 0 сек, вырыв и падение прогресса; предмет внутри камеры не живёт одновременно на карте.
6. **Гены:** один источник -> один результат, зависимости узлов, откат недопустимого выбора.
7. **Метаморфоза:** требования по компонентам, массовый баланс и корректный возврат формы.
8. **Душа:** свойства души сохраняются после смерти, органы/текущее тело не дублируются.
9. **ИИ:** союз/конфликт меняют память и решения, без облачной модели.
10. **Save/load:** два слота, восстановление повреждённого, повторное открытие и отсутствие повторных наград.

## Плейтест без подсказок
- Понятно ли, что нужно тянуть палец **против** направления движения?
- Имеет ли игрок ощущение контроля над скоростью и траекторией?
- Замечает ли он расход воды, не превращает ли это игру в рутину?
- Понимает ли время и условия захвата жука?
- Может ли объяснить разницу между геном, органом и душой?
- Хочет ли он попробовать вторую жизнь?

## Отчёт теста
Дата; версия Unity; git SHA; устройство; build type; команды; сценарии; PASS/FAIL/NOT RUN; скриншоты и логи; известные ограничения.
